# 담당 작업
 - 프론트,백엔드

 - 로그인,회원가입
    - 로그인과 회원가입 기능을 모달로 구현
    - 중복확인과 정규식을 사용하여 회원가입 관리

 - 메인페이지
    - 헤더부분을 고정시켜 스크롤시에도 상단에 고정
    - 모든서비스 부분 마우스 오버시 모달창 on
    - 추천 카테고리 부분에 스크롤 제작
    - 각 게임 카테고리에서 글 작성시 메인페이지에서도 출력
    
 - 유저 검색
    - 검색어 입력시 해당 단어가 들어가는 유저ID 닉네임을 검색하여 출력
